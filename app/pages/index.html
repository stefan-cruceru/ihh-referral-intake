Lamplight Code on GitHub

Every referral, answered with care.

Lamplight helps Illumination Health + Home answer hospital referrals in time. It reads the faxed pages, shows the rule and the page behind every flag, keeps the 2-hour clock, and drafts the follow-up. People make every decision.

Cada referido, respondido con cuidado. Lamplight lee las páginas, muestra la regla y la página de cada alerta, y prepara los borradores. Las personas deciden.

Try the working app

This is the real app, not a mock-up. Its Python code runs inside your browser, so there is no server.

1. Sign in

Pick a made-up staff member. Each has a role. Only the clinical reviewer can say no.

2. Send a practice patient

Open Practice patients and send S01 to S10 to the board. Each gets an owner and a 2-hour clock.

3. Open the card

See each rule, the page it came from, what conflicts, and what is still unknown. Switch to Español.

4. Print the handout

Make the client's next-steps PDF, in color or black and white, in English or Spanish.

What is different here

  • Practice mode only. Every patient is made up.
  • It does not call Claude. Practice reviews come from the organizers' answer key, run through the app's checks.
  • Nothing leaves this page. Close the tab and it is gone.
  • Kipu and Teams are the practice versions. Live ones need IHH's OK.

To review real packets

Run Lamplight on your own computer with a Claude API key. See Try it or Run with Docker.

How it is built

One app on IHH's own computer runs the whole loop. Press play to follow a referral. Open the system map on its own page.
